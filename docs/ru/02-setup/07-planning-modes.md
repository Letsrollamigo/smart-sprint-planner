# 07. Режимы планирования

**Необязательно.** Раздел включает и выключает дополнительные возможности планирования. По умолчанию всё выключено — и это рабочая конфигурация.

## Где

**Настройки проекта → Приложения → Smart Sprint Planner → ПЛАНИРОВАНИЕ → «Режимы планирования»**.

## Переключатели

| Переключатель | Что даёт | Когда включать |
|---|---|---|
| **Прямое редактирование полей задач YouTrack из таблицы спринта** | правка часов прямо в таблице состава без перехода в задачу: оценка записывается по Enter или при уходе из поля (пустое поле её не обнуляет — обнулить можно вводом 0), поля-списки — с подтверждением | почти всегда удобно |
| **Записывать спринт в задачи YouTrack** | при согласовании состава роли выбранное значение спринта проставляется в поле задачи; значение только проставляется и никогда не снимается | когда поле спринта в задачах должно совпадать с согласованным составом |
| **Разрешить планирование с превышением лимитов ресурса роли** | согласование не блокируется, когда аллокация роли больше её ресурса; отрицательный остаток по-прежнему красный | если команда сознательно планирует с перегрузом |
| **Авто-прогноз дат** | кнопка «Спрогнозировать даты» раскладывает задачи по дням очередью; в модели «Простая» переключателя нет | когда даты ставят массово |

Персонального планирования среди переключателей нет: свой ресурс и остаток у каждого исполнителя появляются при модели «Лёгкая» или «Полная», которая выбирается в разделе «Ёмкость» ([глава 10](10-capacity.md)).

## Запись спринта в задачи

По умолчанию выключена. При согласовании состава роли планер проставляет выбранное значение спринта в поле спринта каждой активной задачи состава. Поле берётся из настроек: поле спринта роли ([глава 05](05-roles-fields.md)) или, если оно не задано, общее поле спринта ([глава 06](06-other-fields.md)). Пока поле спринта не настроено, переключатель ничего не делает.

Запись идёт под правами самого пользователя: задачу, которую ему нельзя править, планер не тронет. Значение только проставляется и никогда не снимается — его могли поставить руками до планера, и стирание уничтожило бы чужую работу. Поля с несколькими значениями не поддерживаются: присваивание заменило бы весь список спринтов задачи.

## Превышение лимита ресурса

Пока переключатель выключен (так по умолчанию), состав роли, у которой сумма аллокаций больше ресурса, не согласовать: появляется окно превышения, и валидация не проходит. Переключатель снимает блокировку и окно, отрицательный остаток по-прежнему подсвечивается красным.

Детекция перелимита сохраняется всегда: цифры остаются честными, меняется только то, запрещает ли планер согласование.

## Авто-прогноз дат

Переключатель есть в моделях «Лёгкая» и «Полная»: прогноз раскладывает работу по людям, а в модели «Простая» людей нет.

Кнопка появляется на экране распределения. Она раскладывает задачи роли по календарю очередью: следующая начинается после предыдущей, выходные и отсутствия пропускаются.

Та же кнопка есть на [диаграмме Ганта](../01-overview/09-gantt.md) в режиме «Все роли»: там даты считаются сразу для всех ролей спринта — задача ждёт своих предшественников по связям-зависимостям и по цепочке ролей (с версии 3.48.0).

Это черновик, а не расписание: даты потом правят руками или перетаскиванием на [Ганте](../01-overview/09-gantt.md).
