# 07. Режимы планирования

**Необязательно.** Раздел включает и выключает дополнительные возможности планирования. По умолчанию всё выключено — и это рабочая конфигурация.

## Где

**Настройки проекта → Приложения → Smart Sprint Planner → ПЛАНИРОВАНИЕ → «Режимы планирования»**.

## Переключатели

| Переключатель | Что даёт | Когда включать |
|---|---|---|
| **Персональное планирование** | у каждого исполнителя появляется свой ресурс и остаток внутри роли | когда важно видеть загрузку людей, а не только ролей |
| **Ручной ввод ресурса исполнителя** | ресурс человека вводится руками, а не считается по грейду | когда формула ёмкости не описывает вашу реальность |
| **Использовать персональный ресурс** | остаток роли считается по сумме персональных ресурсов | вместе с персональным планированием |
| **Динамическое редактирование** | правка часов прямо в таблице состава без перехода в задачу | почти всегда удобно |
| **Планирование сверх лимита** | разрешить сохранять состав с перелимитом без модального предупреждения | если команда сознательно переобещает и не хочет диалога каждый раз |
| **Авто-прогноз дат** | кнопка «Спрогнозировать даты» раскладывает задачи по дням очередью | когда даты ставят массово |

## Персональное планирование

Самый весомый из переключателей. Без него роль — это «336 часов», и всё. С ним у роли появляется состав людей, у каждого свой ресурс и остаток, а экран [«Распределение по исполнителям»](../01-overview/07-assignees.md) начинает считать персональные остатки.

Включать стоит, когда команда больше двух-трёх человек: иначе «роль не в перелимите» может скрывать, что вся работа свалена на одного.

## Планирование сверх лимита

Планер и без этого переключателя не запрещает перелимит — он показывает модальное окно с предупреждением. Переключатель убирает окно, оставляя красную метку.

Детекция перелимита при этом сохраняется всегда: цифры остаются честными, меняется только назойливость.

## Авто-прогноз дат

Кнопка появляется на экране распределения. Она раскладывает задачи роли по календарю очередью: следующая начинается после предыдущей, выходные и отсутствия пропускаются.

Это черновик, а не расписание: даты потом правят руками или перетаскиванием на [Ганте](../01-overview/09-gantt.md).
