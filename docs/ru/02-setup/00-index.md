# Внедрение и настройка

Пошаговый ввод планера в новом проекте YouTrack — от установки приложения до первого спринта.

Версия планера — **3.36.0**. Кадры сняты на YouTrack **2026.1**.

## Кому адресовано

Администратору проекта YouTrack, который заводит планер для своей команды. Нужны права администратора проекта; для установки самого приложения — права администратора YouTrack.

Если вы просто работаете со спринтом — вам в [«Обзор»](../01-overview/).

## Как читать

Главы идут в том порядке, в котором стоит настраивать. Обязательные — 01–06, 09, 10 и 20; остальные включают по потребности.

Каждый раздел настроек — отдельный экран с собственной кнопкой сохранения. Настроили раздел — сохранили — перешли к следующему.

## Два уровня настройки

- **Уровень YouTrack** (главы 02, 04) — установка приложения и параметры приложения в проекте. Делается средствами YouTrack.
- **Уровень планера** (главы 05–19) — настройки самого планера: роли, поля, модули, права. Живут на экране **Настройки проекта → Приложения → Smart Sprint Planner**.

Первый уровень открывает доступ ко второму. Пока не задана группа управления настройками (глава 04), второй уровень недоступен: планер работает только на чтение.
