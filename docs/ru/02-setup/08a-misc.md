# 08a. Прочее: язык проекта и диагностика

**Необязательно.** Небольшой раздел с двумя настройками, которым не нашлось места в других.

## Где

**Настройки проекта → Приложения → Smart Sprint Planner → ПЛАНИРОВАНИЕ → «Прочее»**.

## Язык проекта по умолчанию

Планер поддерживает пятнадцать языков. Каждый пользователь выбирает свой в шапке рельса, и выбор запоминается для него лично.

**Язык проекта по умолчанию** отвечает на вопрос, что видит человек, который ещё ничего не выбирал. Если не задан, планер берёт язык браузера, а если и его не понимает — английский.

Задавать стоит, когда команда одноязычная: тогда новому участнику не придётся переключать язык руками.

⚠️ Личный выбор пользователя всегда сильнее проектного значения по умолчанию.

## Панель диагностического лога

Переключатель **«Показывать диагностический лог»** добавляет в низ экрана настроек раскрывающуюся панель с журналом действий планера и кнопками **«Очистить»** и **«Экспорт TXT»**.

Панель нужна при разборе инцидента: в журнале видно, какие запросы ушли на сервер, что вернулось и где сработала проверка прав.

Держите её выключенной в обычной работе — она не вредит, но занимает место и путает пользователей.

## Подробный лог

Отдельный флажок **«Verbose logging (diagnostics only)»** живёт не здесь, а в параметрах приложения YouTrack (глава [04](04-manager-group.md)). Он увеличивает подробность журнала. Включать его стоит только на время разбора.
