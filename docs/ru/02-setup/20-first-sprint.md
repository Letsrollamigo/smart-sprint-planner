# 20. Проверка: первый спринт

**Обязательно.** Настройка считается законченной не когда сохранены все разделы, а когда через планер прошёл живой спринт. Эта глава — сценарий такой проверки на полчаса.

## Шаг 1. Создать спринт

Главное меню → **Smart Sprint Planner** → выбрать проект → **«+ Новый спринт»**. Название и период — любые, хоть «Проверка настройки».

Задайте цель спринта: она понадобится на шаге 6.

**Что проверяем:** проект виден в пикере, спринт создаётся, плашки ролей появились и все в состоянии «Черновик».

## Шаг 2. Проверить ёмкость

Рельс → **«Ёмкость»**. Если выбрана полная модель, проставьте грейды и убедитесь, что «База, ч» ненулевая.

**Что проверяем:** раздел появился, у каждой роли ненулевая сумма вкладов. Ноль означает, что не заполнен календарь или у людей не задано участие.

## Шаг 3. Набрать состав

Рельс → **«Работа с бэклогом»** → отправить в спринт три-пять задач кнопкой **«→ В спринт»**.

**Что проверяем:** задачи попали в роли по своим состояниям, оранжевой полосы про незамапленные состояния нет.

## Шаг 4. Проверить часы

Рельс → **«Аллокация общего ресурса»** → раскрыть карточку роли.

**Что проверяем:** в колонке «Оценка» стоят часы из задач. Пусто означает, что в главе [05](05-roles-fields.md) выбрано не то поле или оценки не проставлены в самих задачах.

Нажмите **«Валидировать»** — роль должна перейти в «Состав согласован».

## Шаг 5. Разложить по людям

Рельс → **«Распределение по исполнителям»** → подобрать исполнителей, назначить задачи, проставить даты.

**Что проверяем:** остаток человека уменьшается при назначении задачи; кнопка **«Валидировать распределение»** переводит роль в «Распределён по людям».

## Шаг 6. Посмотреть все экраны

- **Stand-up** — цель спринта видна, задачи разложены по состояниям.
- **Диаграмма Ганта** — полосы на месте, цвета соответствуют состояниям.
- **История спринтов** — активный спринт в списке.

## Шаг 7. Закрыть и убедиться, что осталось

История → **«Завершить все роли»**.

**Что проверяем:** спринт ушёл в закрытые, раскрывается, состав виден. Это и есть снимок, на котором держится отчётность.

## Если что-то не сошлось

| Симптом | Где искать |
|---|---|
| Проекта нет в пикере | приложение не подключено (глава [03](03-attach.md)) или нет группы управления (глава [04](04-manager-group.md)) |
| «Роли не настроены» | глава [05](05-roles-fields.md) |
| Часы пустые | не то поле оценки (глава [05](05-roles-fields.md)) или пустые поля в задачах |
| Ресурс роли ноль | не заполнена ёмкость (глава [10](10-capacity.md)) |
| Кнопки недоступны | не выданы полномочия (глава [09](09-permissions.md)) |
| Оранжевая полоса в бэклоге | незамапленные состояния (глава [11](11-backlog.md)) |
