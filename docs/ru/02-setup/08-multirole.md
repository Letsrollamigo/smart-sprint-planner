# 08. Мультиролевое планирование

**Необязательно.** Раздел про то, как планер ведёт себя, когда над одной задачей работают несколько ролей.

## Где

**Настройки проекта → Приложения → Smart Sprint Planner → ПЛАНИРОВАНИЕ → «Мультиролевое планирование»**.

## Что настраивается

| Настройка | Что даёт |
|---|---|
| **Сводная таблица по ролям** | над списком ролей появляется общий спойлер: одна задача — строка, роли — колонки, суммы по краям |
| **Кросс-ролевое исключение задачи** | исключение задачи из спринта в одной роли исключает её и в остальных ролях спринта |

## Сводная таблица

Развёрнутая сводка отвечает на вопрос, который иначе требует переключения между ролями: **сколько всего часов вся команда вложила в одну задачу**.

Строка — задача, колонка — роль, на пересечении — аллокация. Правый край — сумма по задаче, нижний — сумма по роли. Перелимит подсвечивается той же краснотой, что и в карточках ролей.

Это read-only срез: править часы здесь нельзя, для этого есть состав роли.

## Кросс-ролевое исключение

С этой настройкой исключение задачи — общее: исключили из спринта в одной роли — сменой статуса включения или корзинкой, — значит исключили из всех ролей. При смене статуса та же причина и та же отметка «кто/когда» уходят во все роли одним актом, окно причины перечисляет роли, куда пойдёт каскад (корзинка удаляет строку без причины). Возврат в спринт не каскадится.

Без неё исключение ролевое: анализ по задаче закончен и исключён, а тестирование продолжается. Полезно на длинных задачах, которые тянутся через несколько спринтов разными ролями.

## Когда это включать

Если у вас одна роль — не нужно вовсе. Если три и задачи регулярно проходят через все — сводная таблица экономит время на планёрке: видно, что задача «стоит» не 40 часов разработки, а 40 + 18 анализа + 14 тестирования.
