# 17. Отображаемые поля

**Необязательно.** Раздел позволяет добавить в таблицы задач любые поля вашего проекта.

## Где

**Настройки проекта → Приложения → Smart Sprint Planner → АДМИНИСТРИРОВАНИЕ → «Отображаемые поля»**.

## Как устроено

Список полей, у каждого — три галочки: в какие таблицы его выводить.

| Галочка | Где появится колонка |
|---|---|
| **Сводная** | сводная таблица аллокаций по ролям |
| **Роль** | состав роли и распределение по исполнителям |
| **Моя роль** | персональный вид «Моя роль» |

![Состав роли с колонками Stage и Unit справа от статуса включения](../../assets/ov-003-role-composition.ru.png)

## Значения не хранятся

Планер не копирует значения полей к себе: он читает их из YouTrack в момент открытия таблицы.

Отсюда два следствия, и оба хорошие:

1. **Видно ровно то, к чему у вас есть доступ.** Поле, скрытое от вас правами YouTrack, останется пустым — планер не обходит права трекера.
2. **Значения всегда свежие.** Поменяли поле в задаче — в таблице оно уже другое, обновлять состав не нужно.

## Сколько колонок можно добавить

Технически — сколько угодно: планер и так везёт значения всех полей задачи одним запросом, и лишняя колонка ничего не стоит по скорости.

Практически — три-четыре. Дальше таблица перестаёт помещаться в экран, и колонки начинают мешать друг другу.

## Что выбирать

Полезны поля, которые отвечают на вопрос «что это за работа»: система, компонент, стадия, направление. Поля, которые и так есть в таблице, — приоритет, состояние, оценка — в списке не появятся вовсе (раздел ниже).

🔴 **Выбирайте только поля, которые у проекта действительно есть и которые заполнены.** «Списанное время» YouTrack, например, кастом-полем не является — оно живёт в учёте времени, и колонка по нему выйдет пустой. Пустая колонка хуже отсутствующей: она выглядит как поломка.

## Чего не будет в списке

Поля, которые планер уже выводит колонками по другим настройкам, в списке не появляются: оценки, факты и исполнители ролей, приоритет, сквозной приоритет, состояние, система, внешний ID. Так одно и то же поле не окажется в таблице дважды.

Поля типа задачи, спринта (общее и ролевые) и версии колонками не выводятся, поэтому в списке они есть: например, «Тип» можно показать отдельной колонкой, не убирая его из «Прочих полей» (с версии 3.43.0).
