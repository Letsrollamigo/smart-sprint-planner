# 21. Чеклист внедрения

Справочная страница: пройдитесь по списку перед тем, как отдать планер команде.

## До настройки

- [ ] В проекте есть поля исполнителя, оценки и факта **для каждой роли**, которую включаете.
- [ ] Поля оценки и факта имеют тип **«период»**, поле исполнителя — **пользовательское**.
- [ ] Есть поток состояний, и состояния **раскрашены**.
- [ ] Включён **учёт времени** в проекте.
- [ ] Если планируете дифф. учёт — заведены **типы работ**, по одному на роль.

## Уровень YouTrack

- [ ] Приложение установлено (глава [02](02-install.md)).
- [ ] Приложение **подключено к проекту** (глава [03](03-attach.md)).
- [ ] Задана **группа управления настройками** (глава [04](04-manager-group.md)) — жёлтой полосы больше нет.
- [ ] Флажок verbose logging **выключен**.

## Обязательные настройки планера

- [ ] Выбраны **роли**, у каждой заданы три поля (глава [05](05-roles-fields.md)).
- [ ] Заданы **поле приоритета** и **поле состояния** (глава [06](06-other-fields.md)).
- [ ] Выбрана **модель ёмкости** (глава [10](10-capacity.md)).
- [ ] Выданы **полномочия** группам (глава [09](09-permissions.md)) — хотя бы «редактирование» и «валидация».

## Модули по потребности

- [ ] **Бэклог**: зоны покрывают все состояния, оранжевой полосы нет (глава [11](11-backlog.md)).
- [ ] **Stand-up**: список «сделано» полон — иначе Velocity занижена (глава [12](12-standup.md)).
- [ ] **Дифф. учёт**: маппинг типов работ заполнен, поля факта больше не правятся руками (глава [13](13-dta.md)).
- [ ] **Связи задач**: описаны типы иерархии и зависимости (глава [16](16-links.md)) — до включения каскадов.
- [ ] **Каскады** оценок и состояний включены вместе (главы [14](14-cascade.md), [15](15-state-rollup.md)).
- [ ] **Отображаемые поля**: выбраны только существующие и заполненные (глава [17](17-display-fields.md)).
- [ ] **Релизы**: маппинг статусов задан (глава [18](18-releases.md)).
- [ ] **Отчётность**: включена И контуры отмечены в матрице прав (глава [19](19-reporting.md)).

## Проверка

- [ ] Пройден сценарий первого спринта (глава [20](20-first-sprint.md)).
- [ ] Спринт закрыт и виден в истории.
- [ ] Кто-то из команды, кроме вас, открыл планер и увидел то же самое.

## Что рассказать команде

- Планер читает часы **из полей задач** — не проставите оценку в задаче, не будет её и в планере.
- Перелимит **не запрещён**, он подсвечен: решение за командой.
- Закрытие спринта делает **снимок**: после него правки задач на историю не влияют.
- Язык планера переключается **в его шапке**, отдельно от языка YouTrack.
