# 09. Управление правами

**Обязательно.** Пока полномочия никому не выданы, планировать сможет только группа управления настройками.

## Где

**Настройки проекта → Приложения → Smart Sprint Planner → АДМИНИСТРИРОВАНИЕ → «Управление правами»**.

## Одна таблица: группа × полномочие

Экран устроен как матрица: строка — группа YouTrack, колонка — полномочие, на пересечении — чекбокс.

| Колонка | Что даёт |
|---|---|
| **Редактирование** | менять состав спринта, часы, даты; сохранять черновик |
| **Валидация** | переводить роль на следующую ступень (состав согласован → распределён) |
| **Назначение исполнителей** | ставить исполнителя задаче в планере |
| **Очистка истории** | стирать историю спринтов проекта |
| **Контур A** | доступ к оперативным отчётам |
| **Контур B** | доступ к управленческим отчётам |

Группы добавляются кнопкой **«Добавить группу»**: список берётся из групп YouTrack.

## Почему полномочий шесть, а не одно

Потому что это разные по цене действия. Поправить часы — обычная работа команды. Сказать «состав согласован» — заявление, за которым стоит договорённость. Стереть историю — необратимо. Увидеть управленческие отчёты — вопрос не техники, а того, кому эти цифры адресованы.

Типовая раскладка:

| Группа | Редакт. | Валид. | Исполн. | Очистка | Контур A | Контур B |
|---|:--:|:--:|:--:|:--:|:--:|:--:|
| Команда доставки | ✓ | | | | | |
| Лиды | ✓ | ✓ | ✓ | | ✓ | |
| Менеджеры продукта | | | | | ✓ | ✓ |
| Администраторы планера | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

## Группа управления настройками — отдельно

Она задаётся не здесь, а в параметрах приложения (глава [04](04-manager-group.md)), и стоит выше всех полномочий этой таблицы: её члены могут менять саму таблицу.

## Проверка прав — на сервере

Планер не полагается на то, что кнопка спрятана. Каждое изменение проверяется на сервере: если запрос пришёл от того, кому нельзя, он будет отклонён независимо от того, что показывал интерфейс.

Поэтому «дать права, спрятав кнопку» не получится — и это правильно.

## Какие группы годятся

🔴 Только **настоящие группы с явным членством**. Неявные группы YouTrack — «All Users», «Registered Users» и авто-группа команды проекта «<Проект> Team» — в этой таблице **не работают**: приложение не видит их в составе групп пользователя, и полномочие не достаётся никому. Проверено на живом стенде: участник такой группы получает отказ сервера при попытке назначить исполнителя.

Если подходящей группы ещё нет — заведите её в YouTrack и добавьте людей явно. Это единственный надёжный способ.

Вложенность планер учесть пытается — членство ищется и в родительских группах, — но полагаться на это не стоит: платформа отдаёт приложению цепочку родителей не всегда. Выдавайте полномочие той группе, в которой человек состоит напрямую.
