# 13. Дифференцированный учёт трудозатрат

**Необязательно.** Модуль избавляет команду от ручного заполнения полей факта: часы попадают в нужную роль сами, из обычных списаний времени YouTrack.

## Где

**Настройки проекта → Приложения → Smart Sprint Planner → АДМИНИСТРИРОВАНИЕ → «Дифф. учёт затрат»**.

## Как это работает

В YouTrack у каждого списания времени есть **тип работы**. Модуль сопоставляет тип работы с ролью планера:

| Тип работы | Роль |
|---|---|
| Investigation | анализ |
| Development | платформенная разработка |
| Testing | тестирование |

Дальше воркфлоу-правило приложения складывает списания по типам и записывает суммы в **поля факта** ролей — те самые, что выбраны в главе [05](05-roles-fields.md).

Человек списывает время как обычно, выбирая тип работы. Планер получает разложенный по ролям факт, и никто ничего не дублирует.

## Что настраивается

| Настройка | Что задаёт |
|---|---|
| **Включить дифф. учёт** | главный переключатель |
| **Маппинг типов работ** | тип работы YouTrack → роль планера |
| **Уведомления план/факт** | предупреждать ли исполнителя, когда факт обгоняет оценку |

## Что нужно сделать заранее

Типы работ заводятся в YouTrack: **Настройки проекта → Учёт времени → Типы работ**. Заведите по одному на роль, до включения модуля.

## Поля факта заполняет воркфлоу

🔴 **После включения модуля не заполняйте поля факта руками** — воркфлоу перезапишет значение при следующем списании. Модуль становится единственным источником этих чисел.

Если нужен ручной ввод факта, модуль включать не нужно.

## Уведомления план/факт

Отдельный переключатель. Когда факт по роли обгоняет оценку, планер оставляет уведомление в задаче. Полезно на длинных задачах; на коротких — шум.

## Что это даёт отчётности

Без дифф. учёта отчёты «Трудозатраты», «План-факт» и «Налог на баги» опираются на то, что кто-то аккуратно заполнил поля факта руками. С ним — на реальные списания. Разница обычно решающая.
