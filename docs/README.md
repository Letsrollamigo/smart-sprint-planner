## About the screenshots · О кадрах

Every screenshot comes from a demo project built for this documentation: two projects,
nine people, one active sprint and three closed ones. **All data is invented** — issues,
systems, people. Any resemblance to real projects is not intended.

Все кадры сняты на демо-проекте, собранном специально для этой документации: два проекта,
девять человек, один активный спринт и три закрытых. **Все данные вымышлены** — и задачи,
и системы, и люди. Совпадения не подразумеваются.

Screens are shot in both languages: files end in `.en.png` and `.ru.png`, and each language
of the documentation shows its own. The planner's own language is switched in the header of
the planner itself; YouTrack's language — sidebar, breadcrumbs, settings navigation — lives
in the YouTrack profile and is switched separately.

Экраны сняты на обоих языках: файлы оканчиваются на `.en.png` и `.ru.png`, каждая языковая
версия показывает свои. Язык самого планера переключается в его шапке; язык YouTrack —
сайдбар, крошки, навигация настроек — живёт в профиле YouTrack и переключается отдельно.
